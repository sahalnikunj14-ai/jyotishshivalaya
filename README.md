# Jyotish Shivalaya Website

Redesigned Next.js 14 website for Jyotish Shivalaya.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build for Vercel

```bash
npm run build
npm start
```

The site is a static-friendly Next.js App Router project and can be deployed directly to Vercel.
